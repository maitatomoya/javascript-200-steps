# JavaScript 200 Steps

JavaScriptを基礎から250ステップで学べる学習Webサービス。
各ステップは「解説→課題→コード編集→実行→答え合わせ」を1ページで完結できる。

## 特徴

- 25章×10ステップ=250ステップのカリキュラム（Hello Worldからクラス・非同期・関数型、よくあるエラー50選まで）
- ブラウザ上のエディタでJavaScriptコードを編集し、その場で構文チェック・実行（Node.js）
- ReferenceError・TypeErrorなどのメッセージをそのまま表示（エラーを読む訓練も学習の一部）
- 1から書かせず、例コードの部分修正・穴埋め・意図的なエラーの修正を中心とした課題設計
- ヒント（段階表示）、模範解答、期待出力による自動クリア判定
- 進捗はブラウザのlocalStorageに保存

## 必要環境

- Node.js 18以上（依存パッケージなし。npm install不要。教材の実行にも同じNodeを使用）

## 使い方

```bash
git clone https://github.com/MaitaTomoya/javascript-200-steps.git
cd javascript-200-steps
node server.js
```

ブラウザで http://localhost:3942 を開く。
